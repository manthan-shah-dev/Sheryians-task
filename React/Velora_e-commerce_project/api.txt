4. Recommended usage
- 70% — dark backgrounds (#080B14, #111827)
- 20% — surfaces, borders and muted text
- 10% — violet, blue and cyan accents
Keep most sections dark, use violet for primary actions, and reserve cyan for small highlights. This makes Velora look modern without making every element glow.
